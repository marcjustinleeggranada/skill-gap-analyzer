# Sources for the Role Profiles

Project: Skill Gap Analyzer, Group 8, BSIT (Bachelor of Science in Information Technology) 3-1. Accessed on November 1, 2026. Every page listed here was opened and read before it was cited. Source IDs match `sources/sources.csv` and the `source` column of `sources/role_profiles_sourced.csv`.

## How skills were counted

- A skill is backed when at least 2 sources for the same role name it or clearly describe it. The source column then lists the IDs, for example `SD-1; SD-2`.
- A skill named by only 1 source is marked `SINGLE SOURCE` plus its ID. A skill no opened page named is marked `UNVERIFIED`. No skill was removed or renamed.
- A skill shown in the skill tags of a posting counts as named. Where a page only hinted at a skill, it was left uncounted.
- Each page was read page by page against the role's skill list with an automated reader, which returned the skill and a short quote. Spot-check a few rows against the pages before the paper cites the counts.
- Some postings are closed or undated. The date column in `sources.csv` is blank when the page shows none. The DILG vacancy notice (2018) and the CompTIA Network+ objectives (2014) are older than the rest and are kept because they describe the role in plain terms.
- Pages opened but not used because they had no job description or failed to load: the Teradyne (Cebu) network administrator page, the Canon (Taguig) cyber security analyst page, the PCCW-HKT (Pasig) IT support page, and one Workable IT support posting that did not load.
